
# Overview

- The game portrays two budding settlements that fight/race for dominance in the same area
- Card types are: Units (Martial and Civil), Buildings, Quick Actions, Long Actions, Enchantment Actions
- Goal of the game: Destroy enemy settlement or win via reaching resource threshold first
- Playing field:

| Settlement Zone                              | Defense Zone                 | Neutral Zone                                                | Neutral Zone                                                 | Defense Zone                   | Settlement Zone                                |
| -------------------------------------------- | ---------------------------- | ----------------------------------------------------------- | ------------------------------------------------------------ | ------------------------------ | ---------------------------------------------- |
| Own Buildings,<br>Enemy Spies,<br>Own Civils | Deploy Zone,<br>Own Martials | Main Battle,<br>Resource Collection,<br>Vanguard Deployment | Main Battle,<br>Ressource Collection,<br>Vanguard Deployment | Deploy Zone,<br>Enemy Martials | Enemy Buildings,<br>Own Spies,<br>Enemy Civils |
|                                              |                              | Raiding Zone                                                | Raiding Zone                                                 |                                |                                                |

---

Every Deck represents a specific Settlement. The Settlement determines:
- Which races/cultures can be in the deck
- Carries a special set of rules and specifics (Some buff certain unit types or buildings, speed up unit production, increase resource gain, etc)
- Is placed in the own *Settlement Zone* at the start of the game

Resources:
- Food and Gold
- Settlements produce a set amount of both by default (varying by settlement type)
- Further resources are produced by:
	- Building cards
	- Sending Units to *Raid* in the *Raiding Zone*
	- Sending Units to Hunt/Gather in the Raiding Zone
	- Action Cards
	- Other card effects

Building Cards:
- Stay on the field until destroyed or otherwise removed
- Can only be placed in the own Settlement Zone (exceptions exist)
- Produce resources, improve units, defend the settlement and much more
- Cost a certain combination of resources to build and in some cases to maintain
- Most only have a health-stat and a effect text (Some have attack-stats)
- Damage is persistent over rounds, can be repaired

Unit Cards:
- Are usually deployed in the *Defense Zone* (Martials) and *Settlement Zone* (Civils)
- Exceptions exist
- Cost a certain combination of resources to deploy and maintain
- Have Health, Defense, Moral, Attack-stats and effect text
- Damage can be mundane or magical
- Damage is persistent over rounds, can be healed
- Moral is reduced when upkeep is not paid (Or via other card effects)
- Moral = 0: Unit deserts or switches sides
- Basic Unit types: Melee, Ranged, Artillery, Mounted, Monstrous, Huge, Flying (Types can combine in one card)
- Rock/Paper/Scissors Strength/Weakness system

Action Cards:
- Cost resources and sometimes other sacrifices/prerequisites
- Long actions take a set time to activate (Minimum one Round), One off usage and effect
- Quick actions take no time to activate, One off usage and effect
- Enchantments usually take 1 Round but quick action enchantments exist, Stay in play until removed

Combat:
- Units can only attack in their own or neighboring zone
	- Ranged can attack 2 zones away or further
	- Artillery can only attack 2 or more zones away
- Units can move 1 Zone or within one zone per turn (exceptions exists)
- Formation matters. Units can only attack units in front of or beside them

Raiding & Hunt/Gather:
- Only in the *Raiding Zone*
- Can only Attack each other, not the main zones
